# Week-221 private policy source snapshot

The [root README](../../README.md) is the canonical Python-to-submission map
and private-pair decision record. This page documents the SK4 source snapshot.

This is a local copy of the SK4 source used for the teammate's Phase 2 private
pair, taken from `/Users/gjimb/SK4` on 2026-11-07. The two baseline CSVs are in
`submissions/`. The copied package, notebooks, research scripts, tests, decision
log, and selected backtest reports make their generation traceable inside this
project. The Phase 2 inputs are shared from `../../data/` instead of being
duplicated here; `../../data/Phase 2 data/` is a compatibility symlink for
the saved generator commands. `eda/30_scenario_pair.py` was adapted to read the sample
submission from `DSDG_DATA_DIR`; its scoring logic was not changed.

Both `_w221_pub.csv` baseline files were regenerated byte for byte in this
project: `dsdg submit <strategy>` followed by `eda/33_fill_public.py` under
`DSDG_DATA_DIR='data/Phase 2 data'`. The public filler uses released outcomes
only for weeks 209–221 and leaves the private rows untouched.

The baseline strategies are `lean_pxlp_mkt_div` and
`insured_hedged_mktcol` in `src/dsdg_supply_chain/strategies.py`. The tariff
separation fix is in `src/dsdg_supply_chain/models/disruption.py` and the
planner cost path in `src/dsdg_supply_chain/policy_lp.py`.

The user-selected final private-only pair in `../../submissions/candidates/` is built
by `../../experiments/private_closure_conditional.py`. It reads these exact
baseline CSVs and week-221 data, then changes only private disruption
probabilities for the open MERROW closure story. The baseline public rows and
all prices, orders, and shares remain unchanged. Run:

```sh
DSDG_DATA_DIR='data/Phase 2 data' python3 \
  experiments/private_closure_conditional.py --alpha 1 \
  --output submissions/candidates
```

`../../experiments/private_closure_backtest.py` checks forecast Brier changes
at historical closure warnings. `../../experiments/private_closure_pair_backtest.py`
scores the pair on historical private-style windows. Both use snapshots cut at
each origin. The scenario test is `eda/30_scenario_pair.py`; it assumes specific
ban and closure outcomes and is a proxy, not a private leaderboard result.

The user confirmed **89.45 public** for each final file; their private scores
remain unknown. `../../methods/check_provenance.py` regenerates the final pair
into a temporary directory and compares it byte for byte. SHA-256 hashes and
each parent-to-final link are in the
[`candidate artifact record`](../../submissions/candidates/README.md).
