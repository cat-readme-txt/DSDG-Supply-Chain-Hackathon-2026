# Source provenance for scored submissions

The [root README](../README.md) is the canonical map of **every Python file**
to its scored submission or research role. This page retains snapshot-specific
provenance details.

Every graded CSV lives once, in `submissions/submission<score>.csv`. These method directories hold the code and notebooks that reproduce them. `data/snapshots/w208/` freezes the ten input CSVs used for all week-208 files, so later data releases cannot silently change a reproduction.

The 54.10 source is the `SK3-67.74` repository at Git commit `eb85f21`. The 60.66 source and notebook match commit `1158114` exactly. The 67.74 directory is a copy of the `SK3-67.74` repository at commit `527bfba`, excluding its `.git`, duplicate data, and duplicate submission CSVs. It includes the research scripts, tests, reports, decision log, and notebooks. The unmatched Kaggle baseline notebook is kept separately in `legacy_unmapped/` because no scored CSV has been proven to come from it.

Run the byte-for-byte reproduction check with a Python environment containing NumPy, pandas, SciPy, and scikit-learn:

```sh
python methods/check_provenance.py --python /path/to/python-with-dependencies
```

The checker uses frozen week-208 inputs for the first eleven files and Phase 2 inputs through week 221 for 84.27, 89.45, 91.36, 92.31, and 92.62. It writes generated files to a temporary directory. The first fifteen match exact bytes. The current 92.62 public optimizer has numerical drift: two released-public orders differ by at most two units and public shares by at most 0.001; forecasts and all private rows match exactly. Its exact scored bytes are preserved. The checker verifies these bounds and does not rewrite graded files.

The scored Phase 2 public diversification files are generated by `experiments/public_diversification_qp.py`; the scored 92.62 joint-order file comes from `experiments/public_joint_order_search.py`. All have the same private rows, so they are public-only research controls.

The newer, private-focused SK4 source and its two baseline CSVs are copied under `methods/sk4_phase2/`. The active private-closure candidate pair is generated from that snapshot by `experiments/private_closure_conditional.py`; see the snapshot README for commands and chronological checks. These files have no reported private leaderboard score.
